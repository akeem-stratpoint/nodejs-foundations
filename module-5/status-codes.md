# HTTP Status Codes

1. 200 — The request succeeded and the server return a response data(Session Token)
2. 401 — Unauthorized request has no (or invalid) credentials
3. 403 — Forbidden the server knows who the user is but they don't have permission to access that other user's data
4. 404 — Not Found
5. 201 — successfully created on the server
6. 400 — Bad Request server can't parse it
7. 204 — the delete succeeded and no response payload return
8. 500 - Internal Server Error 
9. 429 — The user has sent too many requests in a given time
10. 200 — The request succeeded and the server is returning the requested data
